# TermForge

TermForge 是一个 Windows-first 的桌面 SSH 运维控制台，当前处于 **P1 效率增强阶段：P1-01（本地/远程双栏文件管理、跨栏拖拽与传输联动）、P1-02（跳板机与 SSH ProxyJump 链路）、P1-03（SSH 端口转发）、P1-04（快速命令与命令历史）与 P1-05（两窗格会话分屏、定向连接取消与有界自动重连）已交付**。此前已生成 Windows x64 NSIS **未签名测试安装包**；正式签名、实际安装/卸载/升级与干净 Windows 环境验收尚未完成，详见 [0.1.0 发布说明](docs/releases/0.1.0.md) 与 [验收记录](docs/releases/0.1.0-acceptance.md)。P1-03 的真实 SSH 端口转发验收**未执行**；P1-04 与 P1-05 已完成受控 Electron + 本机 `ssh2` 夹具验收，但未在 Windows OpenSSH Server、真实网络抖动与打包安装包中重复验证。另有「Modern Ops / Aurora」界面重构已交付：新应用壳（顶栏全局搜索 + 左导航七项 + 工作台 + 状态栏）、Aurora 极光 / Obsidian 纯色 / Mist 柔光三套经典主题、13 套 DBX 浅/深色板（设置 v6）与可调渐变强度，界面与终端字体均可在设置中切换并实时预览；工作台不再嵌套底部 Dock（SFTP 传输/命令历史/任务中心），右侧 SFTP 文件面板保留并与终端以设置页同款卡片间距分隔，独立 SFTP 文件模块页同时保留，终端工具栏为纯图标；全量回归与三主题 CDP 视觉验收通过，详见 [UI 规格](docs/UI_SPEC.md) 与下文「验证状态」。

> **重要边界**：本阶段已实现主进程真实 SSH 连接、密码/私钥/加密私钥口令/系统 Agent 认证、主机密钥显式信任与删除、多标签独立 SSH 会话、既有 SSH 会话上的真实远程 PTY 与 xterm.js 交互、真实 SFTP 目录浏览与受控文件操作，以及经现有 SFTP 通道执行的真实上传/下载、FIFO 传输队列、进度/速度、取消、手动重试与覆盖/重命名/跳过冲突处理。TASK-008 增加持久化设置中心、脱敏结构化日志与导出、可配置传输并发、未完成任务的中断记录与有序有界退出；壁纸皮肤扩展增加本地图片导入、玻璃面板与浓度控制，保留纯色模式。P1-01 增加本地/远程双栏文件管理与跨栏拖拽：本地面板经主进程只读列举浏览本地目录，拖拽本地文件或目录时目录会在入队前展开为逐文件上传任务（保留文件夹名与相对结构、符号链接不跟随、深度与任务数上限并报告截断），拖拽选中的远程文件下载到面板打开的本地目录。P1-02 增加有序跳板链路（ProxyJump 等价能力）：连接可引用最多 4 个已保存连接作为跳板，链路在主进程用 `ssh2` `forwardOut` 建立，每一跳独立解析凭据并显式校验主机密钥，失败会归属到具体跳板，断开按依赖自内向外清理。P1-03 增加 SSH 端口转发：本地 TCP、远程 TCP 与回环 SOCKS5（仅 no-auth CONNECT）规则由主进程创建监听并转发字节，规则持久化，运行态完全以主进程实际绑定结果为准；本地/远程默认绑定 `127.0.0.1`，非回环地址必须显式确认暴露风险，SOCKS5 强制回环，**不读取、不记录、不向渲染进程暴露转发流量**。P1-04 增加快速命令与命令历史：内置只读诊断命令与用户自定义命令统一复用既有 `terminal:write` / `SshService.writeShell` 通道，`{{identifier}}` 模板由主进程按字面单次替换（不使用 eval、`new Function` 或本地 shell）；发送与插入前必须显式选择已连接且 Shell `open` 的终端，目标失效时不会自动切换或自动重发。命令历史默认**关闭**，仅在设置中显式启用且用户勾选「记录本次发送」时，才把快速命令最终正文作为独立文件保存，不记录终端完整输入输出或退出码。P1-05 增加两窗格会话分屏、定向连接取消与有界自动重连：分屏只保存在渲染运行态（方向、比例与窗格绑定不持久化，最多两个窗格），每个标签仍只有一个 SSH 会话与一个终端实例；窄 IPC `ssh:cancel-connect` 按稳定 `clientId` 取消该标签正在进行的连接，不关闭标签、不影响其他标签或窗格；自动重连默认**关闭**，仅在设置中显式开启后对 `network-error`、`connection-timeout`、`dns-failed`、`connection-refused`、`remote-closed` 五类固定错误码按 1/2/4/8/15 秒退避、最多尝试 5 次，每次重新执行主机密钥校验与认证，不重放输入、不自动信任新密钥、不恢复旧 Shell。**不包含超过两个窗格的分屏、分屏布局持久化、无限或后台自动重连。** **不包含暂停/恢复、断点续传、自动重启执行、远程目录递归下载、远程编辑、文件比较、端口转发自动重启或会话迁移；重启后未完成任务只会显示为「已中断」，端口转发规则保持 `stopped`，不会自动继续。**

## 已实现内容

- 加固的 Electron 主窗口：`contextIsolation`、`sandbox`、禁用 `nodeIntegration` / `webviewTag`、拒绝导航与新窗口、拒绝权限请求、CSP。
- 只读 preload bridge：应用信息、安全存储状态、连接的 list/create/update/remove/setFavorite、SSH 的 connect/disconnect/cancelConnect/getStatus/respondToHostKey/saveCredential、终端的 open/write/resize/close/getStatus 与三类可取消订阅事件、SFTP 的 open/list/stat/mkdir/rename/deleteFile/removeDirectory/close、localFs 的 roots/list（本地目录只读列举）、transfer 的 enqueueUpload/enqueueUploadPaths/enqueueDownload/enqueueDownloadPaths/cancel/retry/resolveConflict/list/clearHistory 与 `onUpdate` 可取消订阅、portForwards 的 list/create/update/remove/start/stop/getConnectionRemovalImpact 与 `onSnapshot` 可取消订阅、quickCommands 的 list/create/update/remove/setFavorite/execute、commandHistory 的 list/remove/clear，以及 settings 的 get/update、hostKeys 的 list/remove、logs 的 getInfo/exportLogs/openFolder、wallpaper 的 get/choose/remove；没有原始 `ipcRenderer` 或通用 IPC 转发。
- 主进程 `SshService`（`ssh2@1.17.0`）：
  - 会话 ID 由主进程生成并独占 Client 生命周期；渲染标签使用独立的稳定 `sshtab-<UUID>` 作为 IPC `clientId`，重连时标签不变、主进程会话 ID 更换；
  - 状态：`connecting`、`authenticating`、`awaiting-host-key`、`connected`、`closing`、`disconnected`、`error` 等；
  - 同一标签（clientId）的重复连接去重；不同标签连接同一连接配置会创建**完全独立**的 SSH transport，最多 32 个活动会话；
  - 90 秒连接超时、keepalive、3 秒断开宽限、窗口关闭/应用退出资源释放。
- 认证方式：
  - **Password**：密码保存在操作系统保护的凭据库；
  - **Private Key**：由主进程读取用户配置的私钥文件，或读取凭据库中的私钥内容；
  - **加密私钥口令**：从凭据库读取口令；
  - **SSH Agent**：Windows OpenSSH Agent 命名管道 / POSIX `SSH_AUTH_SOCK`；Pageant 未支持。
  - 凭据缺失时可弹窗补录；秘密不进入 React/Zustand 状态、连接配置或日志。
- 主机密钥校验：
  - 使用 `ssh2` `hostVerifier` 与实际公钥 blob 计算 OpenSSH `SHA256:` 指纹；
  - 首次连接必须显式确认，确认后才写入 `known-hosts.json` 并继续；
  - 已信任密钥变化时阻止连接；
  - 拒绝、关闭、Esc、遮罩、30 秒超时、存储异常、窗口关闭均不会自动信任。
- 连接配置由主进程持久化到 `userData/connections.json`：版本化信封、strict 校验、首启种子、串行操作、临时文件 + rename 原子写入（Windows 瞬时占用有限重试）、损坏文件停止加载。
- 真实交互式终端（TASK-004，TASK-005 扩展为按标签隔离）：
  - SSH 连接建立后，在当前标签内通过主进程 `client.shell()` 打开 PTY，默认 `xterm-256color`；
  - 键盘输入经固定 IPC 写入同一 SSH 会话的 Shell Channel，远程输出以 UTF-8 流式解码、批量推送到 xterm.js；
  - 窗口尺寸变化经 FitAddon 测量后同步到远程 PTY（`setWindow(rows, cols, 0, 0)`），拒绝零尺寸与非法尺寸；
  - 区分 SSH 已连接与 Shell 已打开；Shell 退出/出错/SSH 断开时显示状态并提供「重新打开 Shell」；
  - 组件卸载、标签切换或 React StrictMode 重放不会关闭 PTY；只有用户主动关闭 Shell、断开 SSH 或应用退出才释放；
  - 终端输出不进入 React/Zustand；渲染进程只保存 Shell 生命周期快照，输出写入 xterm 与有上限的重放缓冲。
- 服务器新增、编辑、删除、搜索与分组：删除确认、会话标签清理、收藏乐观更新与失败回滚、持久化失败横幅。
- 多标签会话生命周期（TASK-005）：
  - ConnectionProfile、主进程 SSH Session 与渲染 Workspace Tab 分离；标签 ID 稳定，重连只替换绑定到标签的主进程会话；
  - 标签顺序与活动标签属于 `workspaceStore`，可序列化会话元数据属于 `sessionStore`；SSH Client、Shell Channel 与 xterm 实例从不进入 Zustand；
  - 可以同时连接多台服务器，也可以为同一服务器打开多个相互隔离的标签；切换标签不调用 disconnect/openShell，xterm 回放缓冲与焦点按标签保留；
  - 关闭标签先标记 `closing`、停止事件处理、清理 xterm/插件/ResizeObserver、等待未决连接（最多 5 秒）并请求主进程释放 Shell 与 SSH；显式失败会保留可重试标签；
  - 被动 SSH 断开保留终端历史、禁用输入、提供重新连接/关闭；手动重连会明确提示将创建新的 SSH 传输与新的远程 Shell，不声称恢复旧进程；
  - 窗口关闭与应用退出走同步清理路径，单个卡住的会话不会阻塞退出。
- 真实 SFTP 远程文件管理（TASK-006）：
  - 主进程在已连接的 SSH 会话上按需打开一条可复用 SFTP 通道；每个标签的会话相互隔离，SFTP 不会自行创建 SSH 连接；
  - 支持主目录解析、目录列举、stat、新建目录、重命名、删除文件、删除空目录与关闭通道；每次操作都重新校验会话归属与连接状态；
  - 目录条目区分目录、文件、符号链接，展示大小、修改时间与 POSIX 权限；缺失元数据显示为未知，不使用伪造值；
  - 路径使用共享 POSIX 规范化（绝对路径、折叠 `.`/`..`、不使用 Windows `path.join`）；名称支持空格、Unicode 与特殊字符，拒绝 `/`、NUL/控制字符与 `.`/`..`；
  - 目录删除非递归：根目录、受保护系统顶层目录、浅层目录、符号链接、非目录与非空目录均被拒绝；
  - 渲染层按标签保存浏览状态，使用请求 ID 与 `sessionId` 守卫丢弃迟到响应；关闭标签/断开 SSH 时清理通道与状态；
  - 变更操作在传输中断/超时后返回 `outcome-unknown`，提示刷新核实且不自动重试。
- 真实 SFTP 上传/下载与传输队列（TASK-007）：
  - 主进程用原生对话框选择本地文件/下载目录，所有本地 `fs` 流、SFTP Read/Write 流、临时文件与提交操作都在主进程执行；渲染进程不接触文件内容，P1-01 起拖拽/面板入口提交的本地路径也由主进程逐条重新校验后才创建任务；
  - 每个文件一个独立任务，单次最多 50 个；上传只接受普通文件，下载只包含选中的普通远程文件，目录与符号链接不会加入任务；
  - FIFO 队列默认全局并发 2、每 SSH 会话并发 1；任务状态为 `queued`、`preparing`、`waitingForConflictResolution`、`transferring`、`cancelling`、`completed`、`failed`、`cancelled`、`skipped`；
  - 进度来自真实传输字节，200ms 限流并计算最近 3 秒速度；总大小未知时 `progress` 为 `null`，不显示伪造的 100%/NaN；提交前最多显示 99%；
  - 支持取消排队/运行中任务与手动重试；重试产生新的 `attempt` 并重新校验源、目标与会话，不进行断点续传；
  - 目标已存在时进入冲突处理，可选择覆盖、重命名或跳过；覆盖前再次检查目标，写入同目录临时文件后通过 rename 提交，不静默覆盖；
  - 取消、失败、超时与会话断开只清理本任务创建的 `.termforge-part-*` 临时文件；应用退出执行有界清理；
  - 上传进入终态后自动刷新仍显示目标目录的 SFTP 标签；传输抽屉展示主进程任务快照、进度、错误指引与冲突操作。
- 本地/远程双栏文件管理与跨栏拖拽（P1-01）：
  - 左侧本地面板由主进程 `local-fs:roots` / `local-fs:list` 只读列举驱动：主目录与磁盘根入口、面包屑、路径输入、返回上一级、按名称/大小/时间排序与隐藏文件开关；只返回名称、类型、大小、mtime 与截断标记，不读取文件内容；
  - 拖拽本地文件或目录到右侧远程面板（或使用面板「上传到远程」）：顶层文件直接落入目标目录，目录在入队前展开为逐文件任务并保留文件夹名与相对结构；符号链接不跟随，目录深度与单次展开任务数有上限，超出时明确报告截断；
  - 拖拽选中的远程文件到左侧本地面板当前目录即下载；跨会话拖拽载荷被拒绝，磁盘根目录与设备路径前缀不能作为目标；
  - 拖拽只传输路径列表与来源会话 ID（自定义 MIME），OS 文件拖入经 `webUtils.getPathForFile` 解析；文件内容、流与提交仍只在主进程流转。
- 跳板机与 SSH ProxyJump 链路（P1-02）：
  - 连接可配置有序跳板列表（最多 4 个），引用已保存连接而不复制其密码/私钥；表单支持从已保存连接添加、上移/下移、移除与「本机 → 跳板 → 目标」路径预览；
  - 主进程按顺序建立链路：跳板 1 直连 TCP，其后每一跳用 `ssh2` `forwardOut` 打开转发通道并作为下一跳 Client 的 `sock`；直连配置不启用任何转发，终端与 SFTP 复用最终目标连接，链路信息不改变既有通道行为；
  - 每一跳独立执行主机密钥校验（按各跳自身 `host:port` 的记录）与凭据解析；跳板凭据保存在跳板自己的加密凭据记录中，补录弹窗标题标注「跳板 N」；跳板被信任不会让目标服务器被自动信任；
  - 失败归属到具体跳板：认证失败、主机密钥变化、`forwardOut` 拨号失败与跳板掉线都会带跳板信息，界面显示「经跳板 N（名称）失败」；任何一跳失败立即终止链路并清理已创建的临时 Client / 转发通道；
  - 断开按依赖自内向外清理，不留下孤立 Client；工作台在连接/认证/主机密钥确认阶段标明当前活动跳，并展示连接路径元数据。
- SSH 端口转发（P1-03）：
  - 规则类型：本地 TCP（本机监听 → SSH `forwardOut` → 目标）、远程 TCP（SSH `forwardIn` → 本机连接目标）与动态 SOCKS5（仅本机回环、no-auth CONNECT、支持 IPv4/域名/IPv6）；规则引用已保存连接，最多 100 条、同时运行 32 条，不保存凭据或私钥；
  - 运行态完全由主进程维护：只有真实监听成功后规则才进入 `running`，绑定失败进入 `error`；SSH 会话关闭即停止规则，不静默迁移到新会话，重连或应用重启后不自动重启，规则一律从 `stopped` 开始；
  - 安全绑定：本地与远程默认 `127.0.0.1`，绑定非回环地址必须在启动弹窗中显式确认暴露风险；服务器拒绝远程绑定时不会自动放宽；SOCKS5 监听固定回环；
  - 生命周期：启动/停止有 10 秒连接/握手与 5 秒停止/解绑上限；解绑失败进入 `error(cleanupPending)` 并阻止编辑、删除与重启；退出按序停止全部规则，清理失败不会被报告为成功；
  - 删除连接时可级联删除其规则，但必须先显示规则数与运行数并显式确认；级联流程先停止并删除规则，任一失败则中止连接删除并可重试；
  - 渲染进程只接收规则与运行态快照（状态、实际绑定端点、连接数、固定错误），不接触 Socket、Channel、转发 payload 或流量日志。
- 快速命令与命令历史（P1-04）：
  - 右侧抽屉含「命令库」与「历史」两个标签页；命令库支持搜索、分类筛选、收藏、复制，自定义命令可新建/编辑/删除，内置命令只读、仅可收藏或复制；
  - 内置命令全部为只读诊断（`uptime`、`df -h`、`free -h`、`uname -a`、`id`、`systemctl status`、`journalctl`、`ss -tulpn`、`ip addr`、`ping`、`tail`、`grep`），不包含重启/停止/删除等会改变服务器状态的命令；
  - 自定义命令支持最多 16 个 `{{identifier}}` 参数，渲染层与主进程都按字面单次替换；参数缺失、包含控制字符或替换后为空时拒绝发送，不做通用 shell 转义承诺；
  - 「插入」只把渲染后的命令写入当前终端输入，不追加回车、不自动执行；「发送并执行」必须经过预览弹窗、显式选择目标终端并确认，主进程重新校验 `tabId`/`sessionId` 绑定、SSH `connected` 与 Shell `open`，目标变化时报错而不是切换或重发；
  - 发送复用既有终端写入通道与渲染层终端写入队列：发送前先冲刷该标签的排队输入，主进程按标签加发送中锁并按请求 ID 去重；不会新建 SSH Client 或任意 `exec` 通道；
  - 命令历史默认关闭（新安装 `commandHistoryEnabled: false`），需在设置中显式开启；开启后发送确认框中的「记录本次发送」默认勾选但可取消；历史最多 200 条，只记录最终命令正文、发送时间与连接/会话元数据，不记录终端输出或退出码，支持搜索、复制、插入、确认后重发、单条删除与清空；
  - 历史保存在独立的 `command-history.json`，与诊断日志分离；正文不写入日志，该文件不额外加密（依赖操作系统账户与磁盘权限），设置页提供开关、清空入口与明文存储说明。
- 两窗格会话分屏、定向连接取消与有界自动重连（P1-05）：
  - 分屏固定为两个窗格（`pane-a`/`pane-b`），支持左右（`row`）与上下（`column`）方向，比例夹取 20%–80%、默认 50%；开关、方向、比例、焦点与窗格绑定只存在于 `workspaceStore` 运行态，不写入设置或会话存储，应用重启后恢复单窗格；
  - 开启分屏时活动标签放入 `pane-a`，若有第二个已打开标签则自动绑定 `pane-b`，否则显示空窗格；空窗格下拉只列出其他已打开标签；点击标签优先填空窗格，无空窗格时仅替换焦点窗格绑定且不关闭原标签；关闭标签只解绑对应窗格，两个窗格都为空时退出分屏；
  - 每个标签仍然只有一个 SSH 会话与一个终端实例；分屏、切换焦点、解绑/重绑窗格与退出分屏都不调用 SSH 连接/断开或新建 PTY，一个窗格断开/重连/关闭 Shell 不影响另一个窗格的会话状态与终端输出；
  - 工具栏提供「左右分屏」「上下分屏」「退出分屏」与方向切换；分隔条支持指针拖动、方向键（`Shift` 加速）、`Home`/`End` 与双击恢复 50%，并带 `separator` ARIA 语义；
  - 新增窄 IPC `ssh:cancel-connect`：只接受稳定 `clientId`（`sshtab-<UUID>`），按标签定向取消进行中的连接尝试（连接、认证、等待主机密钥、手动重连与自动重连尝试）；主进程先收敛为 `disconnected(cancelled)` 再销毁 transport，幂等且无进行中尝试时返回 `cancelled:false`；取消不关闭标签、不影响其他标签或窗格，迟到的连接成功按 epoch 丢弃并主动断开；
  - 自动重连默认关闭（设置 `autoReconnectEnabled: false`），仅在显式开启后按固定 `SshFailure.code` 白名单触发，只重试 `network-error`、`connection-timeout`、`dns-failed`、`connection-refused`、`remote-closed`，不匹配错误消息文本；退避为 1、2、4、8、15 秒，最多 5 次，耗尽后显示「自动重连已停止」并等待用户手动重连；

  - 用户取消/停止自动重连、主动断开、关闭标签、关闭窗口/退出应用与关闭设置开关都会立即清除等待计时器与重连状态；自动重连任务、计时器与尝试次数不持久化，重启后不恢复。

## 使用与验证路径

1. 首次启动会在本地用户数据目录写入 3 个分组与 7 个示例连接（其中 `stage-api-01` 演示性地引用 `stage-bastion` 作为单跳）；示例地址为 RFC1918 私网地址，**不代表可连接的真实服务器**。编辑连接为真实主机后再尝试 SSH。
2. 点击侧栏服务器（或 `+` 选择连接）发起真实 SSH 连接：
   - 密码连接缺少密码时会提示输入密码；
   - 私钥连接可在连接的「凭据引用」中填写私钥文件路径，或在提示中粘贴私钥；
   - 加密私钥会提示输入口令；
   - SSH Agent 连接需要系统 OpenSSH Agent 已运行。
3. 首次连接会显示主机密钥指纹确认弹窗；核对后接受才会继续。关闭/拒绝不会信任密钥。
4. 连接成功后当前标签自动打开远程 PTY。可直接执行 `pwd`、`ls`、`cd` 等命令，输出来自真实远程 Shell。
5. 拖动窗口或切换侧栏观察终端重排；Shell 状态徽章会显示 `cols×rows`，远程 PTY 同步获得新尺寸。
6. 使用工具栏「关闭 Shell」只关闭 PTY，SSH 连接保留；点击状态卡片「重新打开 Shell」会在同一 SSH 会话上创建新 PTY。
7. 使用「断开连接」「取消连接」「重新连接」观察主进程状态变化；断开 SSH 会同时关闭 Shell。
8. 启动 SSH Agent 前后分别尝试 Agent 连接，可查看 `agent-unavailable` 提示。
9. 在「服务器」页删除连接并确认：相关会话标签会关闭；重启应用后删除结果仍保留。
10. 打开已连接的 SSH 标签后进入「SFTP 文件」页：选择该标签，确认显示服务器真实主目录与目录条目。SFTP 复用既有 SSH 会话，不会再次认证；左侧为真实本地面板（主目录/磁盘入口、面包屑、排序、隐藏文件开关），右侧可多选远程文件、拖拽或经工具栏上传/下载。
11. 打开设置页时默认显示外观；依次点击左侧分类（窄屏为顶部标签条），确认每次只显示对应内容，并可用方向键与 Home/End 切换。页面内可切换三套经典主题与 13 套 DBX 色板、DBX 深浅色、经典跟随系统与渐变强度，调整界面字体/字号、终端字体/字号（含实时预览）及终端光标、回滚行数、传输并发、日志级别与壁纸浓度；导入本地 PNG/JPEG 后确认壁纸启用、预览与移除有效，关闭并重启应用后确认设置仍保留。可查看凭据保护状态、主机密钥列表并删除信任记录（会要求确认）。
12. 按 `Ctrl/Cmd+K` 搜索服务器或命令，`Ctrl/Cmd+Shift+P` 打开命令面板。
13. 再次从 `+` 选择同一服务器：应创建新标签及独立 SSH 会话。在两个标签分别 `cd /tmp`，确认工作目录互不影响。
14. 在标签间往返切换：xterm 回放、光标位置与输出应保留，活动标签获得焦点；切换本身不得触发 disconnect 或 openShell。
15. 关闭活动标签、非活动标签和最后一个标签：其他会话不受影响，最后一个标签关闭后回到工作台空状态。
16. 连接中或重连中关闭标签，确认迟到的连接结果不会重新出现在工作区。
17. 断开 SSH（或断网）后确认终端历史保留、输入禁用、可重新连接；重连提示会创建新 SSH 传输与新远程 Shell，原远程进程不会恢复。
18. 关闭应用窗口并退出，确认所有 SSH Client、Shell 与 SFTP 通道被释放；单个无响应会话不应阻止退出。
19. 在 SFTP 页使用面包屑、返回上一级与路径输入在真实远程目录间导航；准备含空格、中文与特殊字符的测试文件，确认名称、大小、修改时间与权限正确展示，缺失元数据显示为未知。
20. 仅在本任务专门创建的测试目录中验证「新建目录」与「重命名」；确认同名目标被拒绝、不会覆盖，并用远程 Shell `ls` 核实结果。
21. 仅删除专门创建的测试文件与空目录；确认包含文件的目录删除被拒绝。不要在真实业务目录执行删除测试。
22. 在一次性测试服务器上尝试删除 `/`、`/etc`、`/home` 与顶层目录，确认主进程拒绝；该操作不应在生产环境验证。
23. 同一服务器打开两个标签，分别浏览不同目录并执行测试操作，确认路径、条目与 SFTP 通道互不影响；关闭一个标签不影响另一个。
24. 在连接中、读取中与变更提交中切换目录或会话，确认旧响应不会覆盖新路径，进行中操作会阻止重复提交。
25. 断开 SSH 后确认 SFTP 显示不可用且不展示其他会话数据；重连后从主目录重新加载。
26. 在可控网络中断下触发变更操作，确认显示 `outcome-unknown`、自动刷新且不自动重试（若无法稳定复现，应记录为未验证）。
27. 上传：在 SFTP 页进入专门创建的测试目录，点击「选择本地文件…」确认弹出的是 Electron 原生多文件对话框，或直接把左侧本地面板中的 1–3 个小文件拖入右侧远程面板；观察传输抽屉出现独立任务、真实字节进度与完成状态。用远程 Shell `ls -la` 核实目标内容与大小；确认上传过程中目录内不会把 `.termforge-part-*` 当作已完成文件展示。
28. 下载：在 SFTP 页多选普通文件后点击「下载」，确认主进程弹出原生目录选择框，或直接拖拽选中文件到左侧面板当前目录；下载完成后在本地目录核对文件内容与大小。选择目录或符号链接不会加入下载任务，界面会显示只有文件会被下载。
29. 冲突：先创建同名远程文件，再上传一个小文件，确认任务进入待处理冲突；分别验证覆盖、重命名与跳过。覆盖前应有再次检查与同目录临时文件提交；重命名应使用用户输入的名称，非法名称会被阻止；跳过后任务为 `skipped` 且目标不变。只在本任务专门创建的测试文件中执行覆盖。
30. 取消与重试：选择较大的测试文件开始上传/下载，在传输中点击取消，确认任务进入 `cancelling` 后结束，并检查目标目录没有残留 `.termforge-part-*`（若存在，说明清理失败并如实记录）。对失败或已取消任务点击重试，确认创建新的 `attempt` 且重新校验，而不是从断点继续。
31. 队列：一次选择多个文件，确认默认最多同时进行 2 个任务、同一 SSH 会话最多 1 个，其余显示排队；关闭传输抽屉不会中断传输，重新打开能看到主进程快照。
32. 生命周期：在传输中关闭 SSH 标签或断开 SSH，确认相关任务变为失败/已停止且不继续写入；重启应用后传输历史不恢复。应用退出时观察是否有界等待，不应因单个卡住的传输永久阻塞退出。
33. 安全边界：确认渲染进程不能传入文件大小、任务状态或流对象；拖拽/面板入口的本地路径会由主进程逐条重新校验（绝对路径、无设备前缀、真实存在、类型允许）。SFTP 与传输只在已连接会话上工作，渲染进程始终拿不到 `SFTPWrapper`、文件流或文件内容。
34. 日志：在设置页确认日志级别、目录、文件数量与写入失败计数；切换级别后触发一次操作并检查新日志是否按级别过滤；点击导出，确认出现原生保存对话框，导出文件不含密码、终端输出或文件内容。若日志目录不可写，界面应显示写入失败计数而不是崩溃。
35. 中断恢复：开始一个较大的传输，在任务未完成时强制结束应用（或正常退出但传输未收敛），重启后打开传输抽屉，确认任务显示「已中断 / 结果未知」、没有重试按钮，并提示核对目标端；确认不会自动重新传输或写入目标。
36. 退出：在传输、Shell 与 SFTP 活动时退出应用，确认退出在有限时间内完成；若某一步清理失败，应用仍应继续关闭，而不是永久卡在退出流程。
37. 设置失败路径：在只读/无权限的用户数据目录或模拟写入失败时保存设置，确认界面提示失败并恢复到保存前的值，不显示“已保存”。
38. 壁纸边界：分别导入真实 PNG/JPEG、超过 20 MiB 的文件、非图片与损坏图片，确认成功项生成预览且失败项显示固定错误；切换轻/标准/浓观察面板透明度变化，确认终端、输入框与表单保持不透明；移除壁纸后恢复纯色模式。
39. 双栏本地浏览（P1-01）：在 SFTP 页确认左侧显示主目录内容；依次使用「此电脑」入口、面包屑、返回上一级、路径输入（相对路径与 `..` 解析）、刷新、排序与隐藏文件开关，确认条目类型/大小/时间与 `资源管理器` 一致，缺失元数据显示未知而不是 0。
40. 拖拽上传（P1-01）：把一个普通文件、一个包含子目录的文件夹分别拖到右侧远程面板，确认顶层文件直接落入目标目录、文件夹保留自身名称与相对结构（逐文件任务）；准备符号链接条目确认被跳过并提示；在超大目录上确认截断提示；确认拖拽期间面板有落点高亮且上传完成后远程列表自动刷新。
41. 拖拽下载（P1-01）：在左侧进入一个专用测试目录，把右侧选中的多个远程文件（含多选）拖入左侧面板，确认下载目标是该目录；尝试拖入磁盘根目录与跨会话拖拽载荷，确认被拒绝并给出提示。
42. 单跳链路（P1-02，需两台真实服务器）：给连接配置 1 个跳板后连接，确认跳板与目标分别弹出主机密钥确认，工作台显示连接路径 `本机 → 跳板 → 目标`，终端与 SFTP 正常；断开后确认两端的 Client 都被释放。
43. 多跳与失败归属（P1-02，需三台真实服务器）：配置两跳链路后连接，确认按顺序逐跳认证；制造跳板失败（错误凭据或禁止转发），确认状态文案带「经跳板 N（名称）失败」且前面的跳板被清理；修复后重连成功。
44. 跳板信任隔离（P1-02）：在跳板上更换主机密钥，确认连接被 `host-key-changed` 阻止并归属该跳板，目标的信任记录不受影响；删除跳板信任记录后重新确认跳板即可恢复，不需要重新确认目标。
45. 本地端口转发（P1-03，需受控 SSH 测试服务）：在「端口转发」页新建本地 TCP 规则，默认绑定 `127.0.0.1`；选择一个该连接已连接的会话启动，核对主进程返回的实际端口并用受控客户端验证双向转发；目标不可达时应显示固定错误；停止后端口释放。重启应用后规则应保持 `stopped`，不得自动监听。
46. 远程端口转发（P1-03，需受控 SSH 测试服务）：默认在服务器 `127.0.0.1` 绑定并验证远程访问；绑定非回环地址时必须在启动弹窗勾选暴露风险确认；服务器拒绝（如 `AllowTcpForwarding no` 或端口占用）时保持 `error`，不得自动放宽绑定；停止后确认远程端口被释放。
47. 动态 SOCKS5（P1-03）：启动规则后仅通过 `127.0.0.1` 使用受控客户端验证 IPv4、域名与 IPv6 目标；确认 no-auth CONNECT、协议错误响应与停止后无残留监听；确认不支持 UDP ASSOCIATE/BIND/SOCKS4，且应用不读取、不记录转发 payload。
48. 会话归属与断线（P1-03）：尝试用其他连接或未连接会话启动规则，应被拒绝；SSH 断开时规则停止且不得迁移到新会话；重连后不自动重启原规则；应用重启后所有规则为 `stopped`。
49. 连接级联删除（P1-03）：删除含运行中规则的连接时，确认先显示规则数与运行数；取消不改变规则；勾选确认后按“停止并删除规则 → 删除连接”执行；若停止规则失败，连接应保留并显示可重试错误，不得报告部分成功。
50. 快速命令入口（P1-04）：在已连接终端点击工具栏「快速命令」，或按 `Ctrl/Cmd+Shift+K`，确认右侧抽屉打开并显示「命令库 / 历史」两个标签页；也可从命令面板进入。记录打开抽屉时是否自动捕获到可发送终端，以及无目标时的提示。
51. 命令库（P1-04）：搜索并切换分类，确认内置命令只读、只能收藏或复制；内置列表应全部为只读诊断命令，不得出现重启、停止或删除类操作。新建自定义命令（名称、分类、描述、正文），在正文中使用 `{{token}}` 等占位符。确认空正文、非法占位符（如 `{{a-b}}`）、未配对 `{{`/`}}`、超过 16 个参数与包含控制字符时被拒绝。
52. 插入与发送（P1-04）：对带参数命令先填写参数，确认预览显示最终正文。点「插入」只写入当前终端输入，不追加回车、不自动执行；点「发送并执行」必须显式选择已连接且 Shell `open` 的终端并再次确认。发送前若终端已有排队输入，应先冲刷该标签的写入队列；用远程 Shell 核实命令只执行一次。
53. 目标失效（P1-04）：打开两个独立 SSH 终端，在发送弹窗中选择终端 A 后关闭/断开 A（或让它被新会话替换），确认弹窗显示目标失效、确认按钮禁用并给出提示，**不会自动切换到终端 B、也不会自动重发**；手动改选 B 后才可发送，并核实只写入 B。
54. 命令历史开关（P1-04）：设置 →「会话与传输记录」→ 命令历史默认「已关闭」。在关闭状态下发送快速命令，确认历史标签页不新增记录；打开开关后再次发送，确认发送确认框的「记录本次发送」默认勾选，取消勾选后本次不记录。打开成功后检查历史只包含渲染后的命令正文、时间与目标会话元数据，不包含终端输出或退出码。
55. 历史操作（P1-04）：在历史标签页搜索、复制、插入、单条删除；对历史记录点发送需再次预览与确认目标；清空历史需二次确认。清空后重启应用，确认历史为空、设置开关保持。若历史文件被破坏，清空应恢复可用状态而不是崩溃。
56. 历史隐私（P1-04）：确认设置页明确说明 `command-history.json` 未额外加密、最多 200 条且与诊断日志分离；在发送并记录后检查 `logs/termforge*.log`，不应出现命令正文或参数值。关闭命令历史开关不会删除已有记录，只阻止新增。
57. 两窗格分屏（P1-05）：打开至少两个已连接标签，使用工具栏「左右分屏」或「上下分屏」，确认两个窗格同时显示各自的真实终端且每个标签仍只有一个终端实例；切换方向、拖动分隔条、使用方向键与 `Home`/`End`、双击分隔条，确认比例在 20%–80% 内变化并恢复 50%；点击窗格标题或标签确认焦点变化。
58. 空窗格与解绑（P1-05）：只打开一个标签时开启分屏，确认出现空窗格，下拉只列出其他已打开标签；选择后绑定成功；关闭一个标签确认只解绑对应窗格且另一窗格会话继续运行；退出分屏后确认所有原有 SSH 会话与终端历史仍保留。
59. 分屏隔离（P1-05）：在两个窗格分别打开独立 SSH 会话并同时输出内容，确认输出不会串流到另一窗格；在窗格 A 断开、重连或关闭 Shell，确认窗格 B 的状态、输入与回放不受影响；分屏操作前后核对 SSH 会话数与 PTY 数没有增加。
60. 取消连接（P1-05）：对一个正在连接/认证/等待主机密钥的标签点击「取消连接」，确认标签保留、状态回到可重连且不关闭另一窗格；重复点击应幂等；在取消与连接成功几乎同时发生时，确认迟到的成功不会重新出现在工作区；对已连接会话使用「断开连接」不应被当作取消。
61. 自动重连默认关闭（P1-05）：在设置 →「会话与传输记录」确认自动重连默认关闭；关闭状态下制造意外断线（例如在受控测试服务端结束通道），确认终端停留终态、不显示倒计时、不自动重试；另一窗格与相邻标签不受影响。
62. 自动重连有界（P1-05）：开启自动重连后再次制造网络类断线，确认显示「等待自动重连」与倒计时，按 1、2、4、8、15 秒退避、最多 5 次；点击「停止自动重连」或「取消自动重连」立即停止，手动重连仍可用；受控条件下确认一次成功自动重连会创建新的 SSH 传输与新 Shell，不重放断线前输入。
63. 自动重连清理与安全（P1-05）：分别制造认证失败、主机密钥变化、主动断开、用户取消、关闭标签、关闭设置开关与退出应用，确认均不会继续重试；确认未知/变化的主机密钥不会被自动信任，重试不会跳过主机密钥或认证检查；界面不得声称旧 Shell、工作目录或前台进程已恢复。
64. 设置 v6（P1-05 + 重构 + DBX 主题/字体）：开启自动重连后检查 `settings.json` 为 v6 且 `autoReconnectEnabled` 为布尔值；在外观区切换经典主题、DBX 色板、DBX 深浅色、界面字体/字号、终端字体/字号与渐变强度后，确认 `theme` 为 16 套风格之一或 `system`、`dbxThemeMode` 为 `system|light|dark`、`uiFontFamily`/`uiFontSize`/`terminalFontFamily`/`terminalFontSize` 落盘且重启后保留；准备 v1–v5 设置文件确认读取后补齐字段且保留既有偏好（旧深色→Aurora、旧浅色→Mist，v5 补 DBX 模式与界面字体默认值）；关闭开关确认等待中的计时器被清除；模拟写入失败确认界面回滚并提示错误。
65. P1-05 未执行场景：真实 OpenSSH Server、真实网络抖动/丢包/长时间断网、五类错误码逐一触发的真实网络条件、系统休眠/唤醒、代理/VPN 切换、NSIS 打包安装包、多窗口并发与屏幕阅读器/输入法下的分屏交互仍需单独验收，不能以受控 `ssh2` 夹具结果替代。

数据文件位于 Electron `userData` 目录（Windows 通常为 `%APPDATA%\TermForge`）：

- `connections.json`：连接与分组配置（不含密码/私钥/口令）；版本 2 起包含有序跳板引用（只保存被引用连接的 ID，不复制其凭据）；
- `credentials.enc.json`：safeStorage 加密的凭据库（密码、私钥内容、口令）；
- `known-hosts.json`：显式信任的主机密钥记录；
- `settings.json`：版本化（当前 v6）、strict schema 校验的非敏感偏好（16 套主题风格与 DBX 明暗模式、界面/终端字体与字号、渐变强度、终端显示、传输并发、日志级别、壁纸开关与浓度、命令历史开关、自动重连开关）；
- `wallpapers/wallpaper.jpg` 与 `wallpapers/wallpaper.json`：主进程转码后的壁纸与展示元数据；原图路径不落盘；
- `transfer-journal.json`：最多 100 条未完成任务展示快照，重启后只用于显示「已中断」，不恢复执行；
- `port-forwards.json`：版本化端口转发规则（本地/远程/动态、绑定地址、目标、所属连接），不含凭据、私钥或运行时状态；重启后规则保持 `stopped`；
- `quick-commands.json`：版本化自定义快速命令（名称、分类、描述、正文、参数）与内置命令收藏 ID；不含凭据、会话数据或命令输出；内置命令定义随应用发布，不写入该文件；
- `command-history.json`：版本化快速命令历史（最多 200 条，最终渲染正文、发送时间与目标会话元数据），不记录终端输入输出、退出码或凭据；**该文件未额外加密**，与诊断日志分离，仅在命令历史开关开启且发送时勾选记录后新增；
- `logs/termforge*.log`：脱敏结构化诊断日志，最多 5 个文件轮转；快速命令正文与参数值不写入日志。

SFTP 目录条目、当前路径与通道不落盘，退出应用后不保留；完整传输历史、队列与速度采样只存在于主进程内存，退出后不保留，仅未完成任务快照会以 `interrupted` 形式跨重启展示。连接配置、凭据和主机密钥不受 SFTP/传输操作影响。进行中的传输会在目标目录创建 `.termforge-part-*`，覆盖提交可能短暂使用 `.termforge-backup-*`；正常结束、取消或失败后由主进程清理，异常退出后可能存在残留，需要人工核查。删除连接会尽力删除该连接对应的加密凭据条目，但不会删除主机密钥信任记录。快速命令与命令历史跨重启保留；删除自定义命令不会删除历史记录，清空历史只影响 `command-history.json`，不影响自定义命令、设置或诊断日志。命令历史关闭时已有记录仍可查看、复制或删除，但不会新增。分屏开关、方向、比例、焦点与窗格绑定只存在于渲染运行态，自动重连计时器、尝试次数与任务同样不落盘；应用重启后恢复单窗格且不恢复任何自动重连任务。

删除或修改 `known-hosts.json` 会使对应端点下次连接重新进入确认流程。

## 安全摘要

渲染进程运行在 `sandbox: true`、`contextIsolation: true`、`nodeIntegration: false` 的窗口中，仅通过冻结的 preload 对象调用 64 个固定领域通道并订阅 7 个推送事件。主进程校验 sender 与主 frame，拒绝所有权限请求、导航、重定向、新窗口和 webview；生产 CSP 的 `connect-src` 为 `'none'`（SSH、SFTP、传输与端口转发由主进程发起）。终端仅以不透明 `sessionId` 与文本数据交互，渲染进程无法获得 `ssh2.Client` 或 Shell Channel；SFTP 仅接受 `sessionId`、POSIX 路径与名称，`SFTPWrapper` 与文件内容始终留在主进程，每次调用都重新校验会话归属。本地列举（`local-fs:roots/list`）只读返回目录元数据，不读取文件内容。传输只接受 `sessionId`、远程路径、任务 ID、冲突策略与拖拽/面板入口的本地路径列表：本地路径由主进程逐条重新校验后才创建任务，文件大小、任务状态与流对象不可由渲染进程指定；本地 `fs` 流、SFTP 流、临时文件与提交操作全部留在主进程。终端输入/输出、命令内容、远程路径、目录内容与传输任务不进入日志或持久化配置。连接元数据由主进程以 strict schema、串行队列和原子写入持久化，错误会归一为安全消息。凭据库只写入操作系统保护后的密文；保护不可用时全部凭据操作失败关闭，没有明文回退。主机密钥 `verify` 永不自动信任或写入，只有用户在确认弹窗中显式接受后才保存记录；未知、变化、超时、拒绝与存储异常均阻止连接。跳板链路（P1-02）的转发 Socket/Channel 与跳板凭据同样留在主进程，每一跳独立执行凭据解析与主机密钥显式信任，跳板被信任不会让目标服务器被自动信任。端口转发（P1-03）复用已连接会话的窄转发接口，Socket 与 Channel 不跨 IPC，渲染进程只收到规则/运行态快照；本地与远程默认绑定 `127.0.0.1`，非回环地址必须显式确认暴露风险，SOCKS5 强制回环且仅支持 no-auth CONNECT；不读取、不记录、不向渲染进程暴露转发 payload；应用重启或 SSH 重连后不自动重启或迁移规则。快速命令（P1-04）不建立独立 SSH Client 或任意 `exec` 通道，只经既有 `terminal:write` 写入已连接会话的 Shell；主进程按 `tabId`/`sessionId` 重新校验会话归属、连接状态与 Shell `open`，目标失效时不自动切换或重发。模板替换为字面单次替换，不使用 `eval`、`new Function` 或本地 shell，参数长度、控制字符与占位符格式均受校验，应用不承诺通用 shell 转义。命令历史默认关闭；只有显式开启且本次发送勾选记录时，才将最终命令正文与目标元数据写入独立的 `command-history.json`，不记录终端输入输出、退出码或凭据；该文件不额外加密，与诊断日志分离，命令正文不进入日志。P1-05 的连接取消仅接受校验过的 `clientId` 并定向取消该标签连接，不返回 Client 或底层错误；自动重连默认关闭、仅在渲染进程内按固定 `SshFailure.code` 白名单有界调度，每次重新执行主机密钥校验与认证，不自动信任、不放宽检查、不重放输入或旧 Shell 状态；分屏仅改变渲染布局，不建立 SSH 连接、不跨窗格共享 Client/PTY/输出，布局与重连计时器不持久化。SFTP 目录删除非递归，根目录、受保护系统目录、浅层目录、符号链接与非空目录均被拒绝。传输取消/失败只清理本任务创建的临时文件，不删除原有用户文件。详见 [SECURITY.md](docs/SECURITY.md)。
