## 重新构建

```bash
npm ci
npm run typecheck
npm run lint
npm test
npm run build
npx electron-builder --win nsis --x64
```

正常环境应运行 `npm run build:win`，它会先执行 `npm run build` 再打包到 `release/`。本机如遇 `release/` 文件占用，可临时指定其他输出目录，再复制安装包与 blockmap：

```bash
npx electron-builder --win nsis --x64 --config.directories.output="<临时输出目录>"
```
