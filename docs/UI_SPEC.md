# TermForge UI 规格

本文记录「Modern Ops / Aurora」重构后的界面结构、交互与视觉约定。连接配置、加密凭据、主机密钥信任、应用设置与诊断日志由主进程持久化；SSH 连接与交互式 PTY 由主进程执行，xterm.js 负责终端渲染。工作区标签与 SSH 会话生命周期分离：标签是稳定身份，每个标签拥有独立 SSH 连接，重连保留标签但创建新会话；工作台右侧提供跟随当前会话的 SFTP 文件面板，终端与文件面板各自为独立卡片、以 14px 间距分隔（对齐设置页侧栏/内容的分隔），同时保留独立 SFTP 文件模块页。两者均读取真实远程目录，并支持经主进程文件流完成的上传、下载、冲突处理、取消与重试，传输抽屉展示主进程任务投影，重启后未完成任务仅显示为「已中断」。外观提供三套固定深浅色的经典视觉风格（Aurora 极光渐变 / Obsidian 纯色深色 / Mist 柔光浅色）与 13 套 DBX 浅/深双模式色板，并提供界面/终端字体预设与字号缩放，同时支持可选的壁纸皮肤模式：用户导入本地图片后，顶栏、侧栏与面板使用半透明玻璃层，终端、输入框、正文与弹窗表单保持不透明；不启用壁纸时与纯色主题完全一致。快速命令通过既有终端输入通道写入，历史默认关闭并独立于应用日志；入口包括 SSH 工具栏、侧栏「命令库 / 历史记录」导航与右侧抽屉。会话分屏（左右/上下、可调比例、空窗格选择）、定向「取消连接」与有界自动重连提示仍保留；分屏与自动重连状态仅存在于运行态，不改变 SSH 连接生命周期。

## 1. 视觉方向

- 紧凑、克制的专业运维控制台；Aurora 与 Mist 使用低饱和弥散渐变背景光斑，Obsidian 为无光斑纯色深色；不使用悬浮夸张卡片或 emoji 图标。
- 16 套视觉风格由 `<html data-theme-style>` 选择：经典 `aurora|obsidian|mist` 固定深浅色，DBX `dbx-pearl|dbx-mist|dbx-graphite|dbx-cobalt|dbx-sage|dbx-amber|dbx-blush|dbx-vscode|dbx-idea|dbx-xcode|dbx-jetbrains|dbx-cursor|dbx-claude` 共用 `data-theme="dark|light"` 并允许独立选择跟随系统/浅色/深色；`data-theme` 同时驱动 `color-scheme` 与 Windows 标题栏按钮颜色。Aurora 为默认风格，经典浅色需求由 Mist 承担。
- 渐变强度可调（0–100，默认 35）：App 壳在 `documentElement` 上设置内联 `--tf-gradient-strength`（0–1），`--tf-gradient-shell` 由三组 `radial-gradient` + `color-mix` 组合品牌色（`#6D7CFF` / `#A855F7` / `#46D9D0`）并按强度调制；Obsidian 与全部 DBX 色板将渐变置为 `none`，强度滑杆不作用于它们。
- 图标统一使用 Lucide React，纯图标按钮必须带 `aria-label` 与 `title`。
- 组件只引用 `--tf-*` 设计 token，不直接写品牌色值；经典主题的 token 调色板集中在 `tokens.css`，DBX 色板以 `--dbx-*` 原始值集中在 `dbx-themes.css` 并统一映射为 `--tf-*`，壁纸态 token 在 `tokens.css`，壁纸层与玻璃效果集中在 `wallpaper.css`。
- 可选壁纸模式：壁纸作为全屏背景，外壳与面板叠加半透明遮罩和细边框，活动项使用低饱和金色强调；终端、输入框、正文与弹窗表单不透明。未导入壁纸时视觉与纯色主题一致。
- 遵循 `prefers-reduced-motion`，减少动画与过渡。

## 2. 应用壳布局

目标视口 `1440×900`：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ Top bar 48px：侧栏开关 · 全局搜索(Ctrl+K) · 桥接状态 · SFTP · 切换主题 │
├──────────────┬─────────────────────────────────────────────────────────┤
│ 主侧栏 260px │ 标签栏 40px                                             │
│ 品牌 + 导航 7│ 工作台：终端卡片（可左右/上下分屏、状态页）             │
│ 服务器/收藏/ │ 右侧 SFTP 文件卡片 380px（跟随当前会话，可开关）        │
│ 分组         │ 终端工具栏为纯图标；底部 Dock 已移除                    │
│              │ 终端卡片与文件卡片之间为 14px 间距                      │
├──────────────┴─────────────────────────────────────────────────────────┤
│ Status bar 26px：工作区 / SSH 会话 / 传输任务 / 主进程信息             │
└────────────────────────────────────────────────────────────────────────┘
```

- 应用壳为三行两列 CSS Grid，整体 `100vh`，不产生页面级滚动；布局尺寸全部走 token（`--tf-layout-*`：顶栏 48、侧栏 260、标签栏 40、状态栏 26；`--tf-dock-sftp-width`：380）。
- 顶部 48px 与 Windows 窗口标题栏合并（`titleBarStyle: 'hidden'` + `titleBarOverlay`）：顶栏空白区域 `-webkit-app-region: drag` 可拖拽窗口，交互控件为 `no-drag`，右侧保留系统最小化/最大化/关闭按钮，按钮区颜色随深/浅主题同步。
- 侧栏折叠后列宽为 0，侧栏组件卸载；顶栏侧栏开关保持可达（`Ctrl/Cmd+B`）。
- 工作台内部：标签栏 40px + 工作台内容区（终端卡片 + 右侧 SFTP 文件卡片）。两张卡片各自带 1px 细边框与 8px 圆角，中间为 14px 间距，与设置页侧栏/内容的分隔方式一致；SFTP 文件卡片可收起，独立 SFTP 文件模块页同时保留。
- 窗口最小 `1024×660`；初始尺寸按主屏工作区收敛至最大 1440×900。

### 响应式

| 断点      | 行为                                                                                                        |
| --------- | ----------------------------------------------------------------------------------------------------------- |
| `≤1240px` | 展开侧栏收窄到 232px；模块头部与工具栏内边距收紧；SFTP 文件卡片收窄到 320px                                 |
| `≤1080px` | 展开侧栏收窄到 200px；导航项内边距收紧；顶栏搜索框收敛为 260px；顶栏桥接状态徽章隐藏；SFTP 卡片收窄到 280px |
| 始终      | 顶栏搜索与 SFTP 面板开关在 1024px 仍完整可见                                                                |

### 壁纸模式

- 根节点 `.app-shell` 使用 `data-wallpaper="on|off"` 与 `data-wallpaper-intensity="soft|balanced|strong"`；仅在已导入图片且开关开启时设置内联 `--tf-wallpaper-image`，纯色模式不创建壁纸层。
- 壁纸层位于布局内容之后，使用边缘渐变 + 半透明遮罩，保证文字对比度；软/标准/浓三档只调整背景可见度与遮罩强度，不改变布局尺寸。
- 玻璃效果只应用于顶栏、主侧栏、状态栏、模块头部、标签栏、终端工具栏、工作台卡片边框、SFTP 文件卡片、设置分区、传输抽屉与浮层菜单；终端容器、xterm 画布、输入框、选择器与模态框表单保持不透明。
- 壁纸态使用低饱和金色作为活动项强调，但状态色（成功/警告/危险）仍沿用原语义 token，不改变状态含义。
- 未导入图片时壁纸开关与浓度控件禁用；导入成功后自动开启并显示 Toast；移除后立即关闭壁纸模式并回到纯色外观。

## 3. 顶栏 / 主侧栏 / 状态栏

### 顶栏（48px）

- 侧栏开关：展开/收起主侧栏，`Ctrl/Cmd+B`，`aria-pressed` 状态同步。
- 全局搜索按钮：`aria-label="全局搜索"`，展示占位文案「搜索连接、命令、设置…」与 `Ctrl+K` 快捷键提示，点击打开命令面板搜索模式。
- 桥接状态：就绪显示「桥接就绪」（绿点），未加载 preload bridge 显示「浏览器预览」（错误点），连接中显示「连接主进程…」。
- SFTP 面板开关：显示/隐藏工作台右侧的 SFTP 文件面板（跟随当前会话）；打开时按钮呈活动态，可访问名称在实际动作间切换「隐藏 SFTP 面板 / 显示 SFTP 面板」，没有会话标签时禁用，`title` 说明当前可用性。
- 切换主题按钮：按 16 套风格顺序循环（`aurora → obsidian → mist → dbx-pearl → … → dbx-claude → aurora`），`title` 明示「当前 X · 点击切换到 Y」，立即应用并持久化；DBX 色板的深浅色沿用当前 `dbxThemeMode`。

### 主侧栏（260px / ≤1240 232px / ≤1080 200px）

- 品牌区：TermForge 图标 + 名称。
- 主导航七项：首页（工作台）、连接管理、SFTP 文件、命令库、历史记录、端口转发、设置。命令库与历史记录打开快速命令抽屉对应页签，其余切换到对应模块；活动项 `aria-current="page"` 并高亮。
- 服务器区：标题「服务器」+ 数量 + `本地配置` 徽章 + 新建连接按钮。
- 搜索：匹配名称、主机、用户名、端口、分组名与标签，即时过滤。
- 常用连接块：无搜索词且存在收藏时展示；搜索时收藏折叠为分组列表首位的「收藏」组（收藏项同时保留在其原分组）。
- 分组：可折叠，带色调标记（tone）、标题与数量；所有项按 `sortOrder` 排列。
- 行内容：主进程 SSH 状态点、名称、`user@host[:port]`（端口 22 时省略）；活动标签对应的连接高亮。
- 状态文本与颜色同步：未连接、连接中、正在认证、等待主机密钥确认、已连接、正在断开、已断开、连接失败；失败时 `title` 附带格式化后的固定错误消息。同一连接存在多个标签时追加「N 个会话」，状态优先取活动标签，其次取任一已连接标签。
- 每行主按钮为该连接新建一个独立 SSH 会话标签；右键或 `…` 菜单：连接服务器、编辑连接、加入/取消收藏、复制地址、删除连接。
- 状态：加载骨架、加载失败+重试、无连接空状态、搜索无结果+清除搜索。
- 底部固定提示「配置本机持久化 · 连接状态来自主进程」。

### 状态栏（26px）

- 「工作区就绪」状态点。
- `SSH 会话 N · 已连接 M · Shell S`（有连接中/认证中/等待确认时追加 `· 进行中 K`）；`S` 为当前处于打开/启动中状态的 PTY 数量。
- 传输按钮：`传输任务 N · 进行中 M`，有待处理冲突时追加 `· 待处理冲突 K`，点击开/合传输抽屉，`aria-expanded` 同步；任务状态来自主进程。
- 「主进程管理 SSH 与文件传输」徽章；浏览器预览时显示「浏览器预览 · 无 SSH 能力」。
- preload 应用信息：就绪时显示 `TermForge v0.1.0 · Windows`；bridge 不可用时提示「浏览器预览 · 未加载 preload bridge」。

## 4. 工作台

工作台结构：标签栏（40px）+ `workbench__body`。`workbench__body` 使用与设置页一致的 `16px 20px` 内边距和 `14px` 间距，内部为两张独立卡片：可左右/上下分屏的终端区，以及右侧 380px 的 SFTP 文件面板（跟随当前会话，可在顶栏或面板头部收起）。底部 Dock（传输队列 / 命令历史 / 任务中心）不在工作台内显示；终端工具栏为纯图标。

### 标签栏

- 每个标签含状态点、会话名、关闭按钮；Shell 就绪时追加终端图标。活动标签高亮，使用 `role="tab"` 并支持 Enter/Space 激活。鼠标中键也可关闭。
- 标签区可横向滚动；滚轮在溢出时垂直滚动转换为横向滚动。
- 标签标题取自连接名；同一连接可同时打开多个独立标签，选择器显示其已打开数量，标签之间不共享 SSH transport。
- `+` 打开服务器选择菜单，列出所有连接与「新建连接…」；已打开连接标注「已打开 N 个会话 · 再次选择会新建独立 SSH 连接」。
- `▾` 打开所有会话菜单（无会话时禁用），显示每个标签的状态并可切换。
- 关闭活动标签后激活右侧邻居，否则左侧；关到空时工作台显示空状态。关闭期间标签显示为 `closing` 且关闭按钮禁用；关闭标签会按序停止终端、取消未决连接并请求主进程断开，仅影响该标签的独立会话。
- 标签排序、活动标签与分屏绑定由 `workspaceStore` 管理；关闭标签不改变其他标签的 SSH 连接。分屏开启时，点击标签会优先放入空窗格；没有空窗格时替换焦点窗格的绑定，但不会关闭被替换标签的 SSH 会话。

### SSH 工作区（中央）

- 每个终端窗格头部：会话名、`user@host:port`、SSH 状态文本与状态点、`SSH` 徽章；SSH 已连接时追加 Shell 状态徽章与 `cols×rows`。
- 操作按状态出现：「断开连接」（已连接）、「取消连接」（连接中/认证中/等待主机密钥/手动重连进行中）、「重新连接」（失败/已断开）、「输入凭据」（失败且可补录）；Shell 打开/启动中时显示「关闭 Shell」。
- 分屏操作固定在窗格头部：「左右分屏」「上下分屏」（未分屏时）；分屏后改为「左右」「上下」方向切换与「退出分屏」。按钮 `title` 明确「仅改变布局，不建立新的 SSH 连接」「仅合并布局，不关闭任何 SSH 会话」。
- 终端工具栏的全部操作按钮均为纯图标样式（无文字标签），每个按钮带 `aria-label`（可访问名称保持原文字）与 `title` 说明；「断开连接」保持次要红色外观。
- 取消连接只作用于当前标签正在进行的连接尝试：保留标签与终端历史画面，不关闭其他标签或另一窗格；取消后显示已断开/已取消状态，可手动重新连接。
- 「快速命令」按钮始终可用：打开右侧快速命令抽屉并捕获当前标签作为发送目标（仅当 SSH 已连接且 Shell 已打开）；也可通过命令面板动作或 `Ctrl/Cmd+Shift+K` 打开。
- SSH 状态区域根据主进程快照展示：
  - 正在连接服务器、正在认证、等待主机密钥确认；配置跳板链路时标明当前活动跳（如「正在连接跳板 N/M 名称（host:port）」「正在对跳板 N/M 名称进行认证」）；
  - 连接失败：固定错误消息 + 针对凭据、主机密钥变化、Agent 不可用等场景的指引；失败归属到跳板时前缀「经跳板 N（名称）失败」；
  - 已断开：主动断开或远端关闭；
  - 取消/正在断开。
- 自动重连（设置默认关闭）在终端区域显示 `role="status"` 提示条：
  - 等待重试：「等待自动重连」+「将在 N 秒后进行第 X/5 次自动尝试」+「停止自动重连」；
  - 正在重试：「正在自动重连」+「第 X/5 次自动尝试正在重新执行 SSH 认证与主机密钥校验」+「取消自动重连」；
  - 次数耗尽：危险色提示「自动重连已停止」，说明已尝试 5 次，需检查网络或服务器后手动重连；
  - 提示条明确「不会恢复旧的远程 Shell 或重放输入」「仅重试网络类错误，不会自动信任新主机密钥」。自动重连期间不显示会误导为已连接的终端就绪状态，也不自动重放断线前的终端输入或快速命令。
- SSH `connected` 后，终端区域直接渲染 xterm.js 与真实远端 PTY：
  - 自动打开 `xterm-256color`，无需额外按钮；
  - 键盘输入实时写入远程 Shell，不做本地回显；ANSI 颜色、UTF-8 与光标控制由 xterm 渲染；
  - Shell `opening`/`closing` 显示半透明忙碌遮罩；
  - Shell `closed`/`exited`/`error` 显示状态卡片：退出码/信号或固定错误、SSH 连接仍保留的说明、「重新打开 Shell」按钮与会话 ID；重新打开会在同一 SSH 会话上创建新 PTY；
  - 空容器/隐藏视图不会发送 0×0 尺寸；重新可见后由 ResizeObserver 重新测量。
- SSH 断开但标签曾打开过终端时，保留本地只读历史画面并叠加提示；重新连接会为该标签创建新的 SSH 传输和新 Shell，明确说明原远程进程与工作目录不会自动恢复。
- 每个标签的终端 Pane 始终挂载；单窗格模式下仅活动标签可见，分屏模式下绑定到两个窗格的标签同时可见，其余标签隐藏。切换标签、切换视图或调整分屏都不会创建、关闭或重连 SSH/PTY。
- 终端底色使用 `--tf-color-terminal`：三套经典主题均保持深色（Aurora `#0a0e17` / Obsidian `#090c12` / Mist `#0c1117`）；13 套 DBX 色板无论界面明暗都使用该色板的深色终端背景与 ANSI 16 色，浅色主题不翻转终端配色。
- 分屏布局（P1-05）：
  - 仅两个窗格（`pane-a`/`pane-b`），方向为左右（`row`）或上下（`column`）；开启分屏时当前活动标签固定在 `pane-a`，若存在其他已打开标签则自动绑定到 `pane-b`，否则显示空窗格。
  - 空窗格卡片包含「空窗格」标题、说明「分屏只改变布局，不会创建新的 SSH 连接」、已打开会话下拉（排除已绑定到另一窗格的标签）与提示「也可以点击标签栏中的其他会话」；没有可放入会话时下拉禁用并显示「没有可放入的其他会话」。
  - 每个窗格顶部显示窗格标识、会话名、SSH 状态与「聚焦此窗格」；非焦点窗格降低强调，点击窗格或标题聚焦。移除按钮只把该窗格解绑为空窗格，不关闭标签、不断开 SSH。
  - 两个窗格之间为可拖拽分隔条（`role="separator"`、`aria-label="调整分屏比例"`），支持指针拖动、左右/上下方向键（Shift 加大步长）、Home/End 与双击恢复 50%；`aria-valuemin/max/now` 同步 20–80% 范围。比例限制在 20%–80%，默认 50%。极窄视口仍保留两个窗格，不自动合并或关闭会话。
  - 关闭标签时把对应窗格解绑为空窗格；两个窗格都没有绑定标签时才自动退出分屏。关闭标签只结束该标签自己的会话，不会断开或重连另一窗格的 SSH 会话；若关闭的是焦点窗格，焦点转移到另一窗格仍绑定的标签。
  - 分屏布局、方向、比例与窗格绑定只保存在运行态，刷新或重启后回到单窗格；不写入设置、连接或会话存储。
- 元数据：目标、认证方式、连接时间、已确认的主机密钥算法与指纹；配置跳板时追加「连接路径」`本机 → 跳板 1 → … → 目标服务器`，已连接说明注明经 N 个跳板建立。
- 关闭标签期间状态页操作禁用，标签按顺序完成终端解绑、未决连接等待与主进程断开；失败时保留标签并提示重试。
- 工作台空状态：「没有打开的会话」+ 连接第一台服务器 / 管理服务器 / SFTP（演示）。说明文案「连接到一台服务器以发起真实 SSH 握手，并在终端标签内打开远程 PTY。终端输入与输出不经过本地 shell 模拟。」

### SFTP 文件面板（380px，右侧）

- 头部：`SFTP` 标题、连接名、状态徽章（已连接/读取中/不可用），并提供「在 SFTP 页打开完整双栏视图」与「隐藏 SFTP 面板」。

- 数据为真实远程目录，来自主进程 SFTP 通道，不展示模拟文件；新建目录、重命名、删除等完整操作仍在独立 SFTP 文件页完成。

## 5. 主机密钥确认

- 未知主机密钥到达时，主进程推送 challenge；UI 以模态框展示连接名、`host:port`、算法与 OpenSSH `SHA256:` 指纹；challenge 来自跳板时追加「跳板」元数据（第 N 跳 · 名称），说明文字注明该信任仅适用于此跳板、最终目标仍会单独要求确认。
- 说明：确认前连接不会继续；指纹应通过可信渠道核对。
- 操作：「信任并继续」与「拒绝连接」。拒绝、关闭按钮、Esc、点击遮罩都会发送 `accepted: false`。
- 请求 30 秒后过期；过期后弹窗关闭，会话进入 `host-key-timeout`。
- 同一会话的 challenge 排队处理；会话进入终态时清理提示。
- 弹窗不是“自动接受”：任何关闭路径都等于拒绝。

## 6. 凭据补录

- 错误码为 `credential-required` / `credential-invalid` / `authentication-failed` 且带 `credentialKind` 时，工具栏显示「输入凭据」，或由状态事件自动打开弹窗；失败归属跳板时标题标注「跳板 N」，保存的凭据写入该跳板自己的连接记录。
- 密码：单个密码输入框；私钥：多行文本域；加密私钥：口令输入框。输入框为非受控，提交后立即清空 DOM 值。
- 保存成功后关闭弹窗、显示 Toast，并重新发起该连接的 SSH 连接；保存失败保持弹窗并展示固定错误。
- 秘密只通过 `ssh:set-credential` 发往主进程，不写入 React state、Zustand、Toast 或日志。

## 7. 服务器管理页

- 页头：英文 eyebrow、`本机持久化` 徽章、说明文字、「刷新」与「新建连接」按钮。
- 工具栏：搜索框、`显示 N / M` 计数、说明「凭据引用不含密码或私钥内容」。
- 表格列：名称（含收藏与「当前」/「会话」标记）、地址、分组、认证方式、标签、SSH 状态、操作（新建 SSH 会话标签、编辑、删除）。
- SSH 状态来自 `sessionStore` 的主进程快照；同一连接存在多个标签时标记会话数量；未打开连接显示「未连接」，失败消息通过状态项的 `title` 展示。
- 状态包括加载中、错误重试、空列表、搜索无结果；加载状态与侧栏共享同一个 `connectionStore`。
- 持久化失败时显示可关闭的错误横幅；表单提交失败在对话框内显示内联错误。
- 删除连接需要二次确认；删除弹窗先加载该连接的端口转发影响：加载中禁用确认，读取失败显示 `role="alert"` 与「重试检查」；无规则时显示「没有关联的端口转发规则」；有规则时展示规则总数与运行中数量，并要求勾选「我已确认停止并删除这 N 条端口转发规则，随后再删除该连接。」后才允许提交。成功后关闭相关会话标签并请求主进程断开，说明会尽力删除该连接的密码/私钥/口令凭据条目，但不会删除主机密钥信任记录；级联删除失败时保留弹窗并显示固定错误，用户需先重试停止相关规则。
- 搜索匹配名称、地址、用户名、分组、认证方式与标签。搜索词与侧栏共享。

## 8. 连接编辑器

模态宽度 640px，最大高度受视口约束；表单动作区使用 sticky 底部栏，内容滚动时按钮仍可达。

字段与规则：

| 字段     | 规则                                                              |
| -------- | ----------------------------------------------------------------- |
| 连接名称 | 必填，≤64 字符                                                    |
| 主机     | 必填，≤253；支持主机名、IPv4、IPv6；禁止协议、路径、端口、空格等  |
| 端口     | 必填，纯数字，1–65535                                             |
| 用户名   | 必填，≤64 字符                                                    |
| 认证方式 | `Password` / `Private Key` / `SSH Agent`                          |
| 分组     | 必选                                                              |
| 标签     | 逗号分隔（中英文逗号均可），去重，最多 8 个，每个 ≤24 字符        |
| 凭据引用 | Private Key / SSH Agent 时显示；可选，≤512 字符；只保存非机密引用 |

- Password 模式不渲染密码输入框；密码在首次连接失败后通过凭据弹窗补录，保存在操作系统凭据库。
- Private Key 的凭据引用可填写私钥文件路径（绝对路径、`~` 或 `file://`），也可留空并在凭据弹窗中粘贴私钥。
- SSH Agent 连接不使用密码/私钥；Agent 不可用时连接失败并提示启动系统 Agent。
- 校验失败显示顶部错误摘要并将焦点移到首个错误字段；字段错误使用 `role="alert"` 与 `aria-invalid`。
- 高级选项可展开，显示禁用的「保持连接间隔（30 秒固定）」与可用的「跳板机 / ProxyJump」编辑器：从已保存连接中选择添加（自身排除、不可重复、上限 4 个），列表按连接顺序显示序号、名称与 `user@host:port · 认证方式`，可用上移/下移调整顺序、可逐个移除，并实时预览「连接路径：本机 → 跳板 1 → … → 目标服务器」；引用不存在的连接会就地提示。说明文字注明每跳使用各自认证方式与主机密钥信任记录，跳板被信任不会自动信任目标。
- 提交按钮文案为「创建连接」/「保存修改」；成功后写入主进程本地存储，失败时显示内联错误并允许重试。

## 9. SFTP 文件页（真实远程）

- 页头：`SFTP` eyebrow、`真实远程通道` 徽章、说明「SFTP 复用工作台中已建立的 SSH 会话；不会自行新建连接，也不会在渲染进程持有 SSH Client」、已连接会话计数、SSH 会话选择器。选择器列出所有工作区会话及其 SSH 状态；非 `connected` 会话仍可选中，但显示不可用状态与「前往工作台重连」。
- 没有任何 SSH 会话时显示「还没有 SSH 会话」空状态；有会话但均未连接时额外提示 SFTP 只复用现有连接，不会在后台自行建立 SSH 传输。
- 双栏：左「本地」为真实本地面板（主进程只读列举），右「远程」为真实 SFTP 数据；两栏互为拖拽源与落点，也可用工具栏按钮与系统对话框完成上传/下载。
- 本地面板：显示当前本地路径（主目录/磁盘入口、面包屑、路径输入、返回上一级、刷新）、名称/大小/时间排序与隐藏文件开关；条目只展示名称、类型、大小与修改时间等元数据，不读取文件内容；渲染端先拦截相对路径与设备路径前缀（`\\.\`/`\\?\`），主进程仍再次校验。支持单选与 `Ctrl/⌘`、`Shift` 多选；对被选中的普通文件/目录提供「上传到远程」（目标为当前远程目录）与「打开传输队列」，并保留系统对话框上传入口。显示会话/远程目录可用状态、本会话上传任务数与进行中数量；会话未连接或远程目录未就绪时禁用上传。
- 本地面板状态：首次进入定位到主目录；「此电脑」视图列出主目录与磁盘入口；空目录、读取失败（保留旧列表并显示横幅与重试）与截断警告（条目超过 5,000 上限）分别展示固定文案。名称支持空格、Unicode 与特殊字符；符号链接标记类型且不跟随。
- 远程面板头部：会话名、目标 `user@host:port`、状态徽章（`SFTP 已连接` / `读取中` / `SFTP 不可用`）。
- 工具栏：返回上一级、面包屑导航、输入远程路径、刷新、新建目录、上传本地文件、下载选中文件。上传按钮把文件送入当前远程目录；下载按钮仅在选中至少一个文件时可用；也可直接在两栏之间拖拽。路径输入支持绝对路径与 `../` 解析，校验失败显示字段错误；说明规范化不代表服务器授权。
- 列表列：名称（目录/文件/符号链接图标）、大小、修改时间。单击选择，`Ctrl/⌘` 切换多选，`Shift` 连选，双击目录进入；目录与符号链接不可作为下载源。多选时底部显示已选数量、其中文件数与目录/链接数，并说明「下载只会包含文件」。
- 选中单个条目时显示类型、权限与完整路径，并提供「重命名」「删除」；多选时只提供下载。文件与符号链接不作为下载源；上传与下载均为单文件任务：拖入的本地目录会在入队前展开为逐文件任务（保留文件夹名与相对结构、符号链接不跟随、深度与任务数上限、超出截断并提示），下载不接受目录或符号链接。
- 上传流程：入口有两个 —— 点击上传打开原生多选文件对话框（单次最多 50 个文件），或从左侧面板拖拽/使用「上传到远程」。拖入目录会递归展开为逐文件任务并保留文件夹名与相对结构；符号链接被跳过、不支持的类型被计数提示；超出深度或任务数上限时报告截断。每个文件创建独立任务并加入主进程队列，目标为当前远程目录。取消对话框不创建任务。同名目标会进入 `待处理冲突`，由传输抽屉选择覆盖、重命名或跳过。
- 下载流程：选中一个或多个远程文件后点击下载（打开原生目录选择器），或把选中文件拖入左侧面板当前目录；每个文件创建独立任务，目标为该本地目录。目录、符号链接与非普通文件不会加入下载任务；磁盘根目录不能作为下载目标，跨会话拖拽载荷被拒绝并提示。
- 传输反馈：入队成功显示 Toast（加入 N 个上传/下载任务，拖拽入口附带跳过的符号链接数与截断提示）；入队失败显示固定错误。上传任务进入终态（完成/失败/取消）后，当前匹配该会话与目标目录的远程列表会在 200 ms 防抖后自动刷新；不把未完成的临时文件展示为已完成文件。
- 元数据：目录与符号链接不显示字节大小；文件大小缺失、修改时间缺失或权限无法解析时显示 `—` / 「权限未知」，不得伪造 0 或当前时间。名称原样展示空格、Unicode 与特殊字符。
- 状态：
  - `opening`：正在打开 SFTP 通道；`loading`：正在读取远程目录；
  - 空目录：显示「此目录为空」，说明空目录可作为安全删除目标；
  - 首次读取失败：固定错误、按错误码给出的指引与「重试」；
  - 已有条目的刷新失败：保留列表并显示带重试的错误横幅；
  - SSH 断开：显示「SFTP 不可用」，不展示其他会话的目录数据，提供重新打开入口；该会话的传输任务由主进程终止。
- 新建目录 / 重命名：
  - 使用模态框输入名称，实时显示目标完整路径与父目录；创建不会递归创建多级路径，重命名保持同一父目录。
  - 名称校验：非空、≤255 字符、不能纯空白、不能为 `.`/`..`、不能包含 `/`、NUL 或控制字符；支持空格与 Unicode。
  - 目标已存在时服务器拒绝，不静默覆盖；重命名新名称与原名相同会被前端阻止。
- 删除：
  - 二次确认展示类型、名称与完整路径；文件提示不可恢复，符号链接提示只删除链接本身，目录提示仅在为空时删除。
  - 不提供递归删除；根目录、常见系统目录、顶层浅目录、符号链接与非空目录由主进程或服务器拒绝。
  - 提交期间禁用按钮与取消；失败显示固定错误；`outcome-unknown` 明确提示结果未知、自动刷新目录且不自动重试。
- 切换 SSH 会话时重置路径、条目与选中项；旧会话或旧目录的迟到响应不得覆盖当前状态。
- 页脚固定说明：删除仅限文件、符号链接或空目录，不会递归删除目录内容；传输会在目标同目录写入 `.termforge-part-*` 临时文件，提交前重新检查冲突；不支持断点续传或暂停恢复。

## 10. 传输抽屉（真实任务）

- 从右侧滑入的 portal 对话框，标题「传输队列」+ `主进程` 徽章；带遮罩、`aria-modal`、Esc 与关闭按钮，不阻塞主工作区。关闭面板不会中断传输。
- 副标题说明任务状态、文件流与临时文件均由主进程维护。
- 工具栏：`共 N 个 · 进行中 M`，有待处理冲突时追加 `· 冲突 K`；提供「从主进程刷新」与「清空已结束」。清空只移除已完成/失败/已取消/已跳过记录，不删除进行中或待处理冲突任务。
- 每个任务：方向图标、文件名、状态徽章、源与目标路径、进度条、`已传输 / 总大小`、百分比、实时速度与尝试次数。
- 状态文案：排队中、准备中、待处理冲突、传输中、正在取消、已完成、失败、已取消、已跳过；状态不只依赖颜色。
- 进度：有总大小时显示 0–99% 的真实字节进度，完成时才显示 100%；总大小未知时显示「大小未知」与不确定进度条，不伪造 100%、NaN 或 Infinity。速度来自主进程滑动窗口，低频更新。
- 冲突处理：`待处理冲突` 任务内联展开冲突面板，展示目标路径与建议名称，提供「覆盖」「重命名」「跳过」；重命名需通过文件名校验（上传校验远程名称，下载校验本地名称）。面板说明覆盖会先写同目录临时文件再替换目标，提交前会再次检查服务器状态。提交期间按钮禁用，失败显示固定错误。
- 操作：排队中、传输中或待冲突任务可「取消」；`正在取消` 显示「等待主进程停止…」并禁用重复操作。失败或已取消可「重试」，重试会创建新尝试次数并重新校验源、目标与会话；已完成、已跳过与正在取消不提供重试。
- 错误：显示主进程返回的固定消息与按错误码给出的指引（源缺失/变化、目标变化、连接丢失、权限、超时、结果未知、临时文件清理失败等）；不展示原始 fs/SFTP 错误或堆栈。
- 空状态：「队列为空」，说明在 SFTP 页选择/拖拽本地文件上传或选中远程文件下载后任务会出现在此处。
- 页脚固定说明：不支持断点续传或自动重启执行；上次退出时未完成的任务重启后显示「已中断 / 结果未知」，应核对目标端后重新发起；取消和失败会清理本任务创建的临时文件；应用退出时最多进行有界清理。

## 11. 端口转发页（P1-03）

- 页头：`端口转发` eyebrow、`主进程` 徽章、说明「复用已连接的 SSH 会话转发 TCP，支持本地、远程与 SOCKS5 动态转发；规则持久化，运行时状态以主进程为准」、规则总数/运行中数量、「新建规则」与「刷新」按钮。
- 列表列：名称与类型徽章、关联连接、监听地址、目标（本地/远程显示 `targetHost:targetPort`；动态显示「SOCKS5 · 本机回环」）、状态、绑定端点、活动连接数、失败/清理提示、操作。
- 状态文案：已停止、启动中、运行中、停止中、错误；运行中显示主进程返回的 `boundAddress:boundPort` 与 `activeConnections`，不只依赖颜色。存在 `cleanupPending` 时显示「清理未完成」徽章与说明，禁止删除并提示先重试停止。错误行展示固定失败消息，不显示原始 `ssh2` 错误。
- 绑定会话：运行中规则显示主进程返回的 `sessionId`（等宽小字、`title` 展示完整值），明确规则绑定到启动时选择的会话；会话断开后规则以 `session-ended` 停止，不自动迁移到重连后的新会话。
- 操作：
  - 「启动」打开启动弹窗；弹窗只列出与规则连接匹配且 SSH 状态为 `connected` 的会话（同一会话去重，活动标签优先），没有可用会话时显示说明并禁用确认。
  - 本地/远程规则的监听地址不是回环地址时，启动弹窗显示暴露风险提示与「我确认该端口会暴露给其他主机」复选框；未勾选时「开始转发」禁用。SOCKS5 规则不显示该选项，监听地址固定为 `127.0.0.1`，并说明首版只支持本机 SOCKS5 CONNECT。
  - 「停止」在运行中/启动中可用，提交期间禁用重复操作；失败时保留错误状态与清理提示，不显示成功。
  - 「编辑」只在停止/错误状态可用；编辑不能改变规则类型与关联连接，凭据不存在于表单。运行中/停止中规则的编辑与删除均禁用，`title` 说明需先停止并等待清理完成。
  - 「删除」需二次确认，展示名称、类型、监听与目标；运行中/清理未完成的规则不可删除。
- 新建/编辑模态：名称（1–64 字符，不含控制字符）、类型（新建时可选本地/远程/SOCKS5；编辑时固定）、关联连接（新建时可选；编辑时只读）、监听地址（本地/远程为 IPv4/IPv6 字面量，默认 `127.0.0.1`）、监听端口、目标主机与端口（仅本地/远程）。动态转发隐藏监听地址与目标字段，并提示「SOCKS5 仅监听 127.0.0.1，不提供局域网代理」。表单校验错误使用 `role="alert"`，提交失败保留输入并显示固定错误。
- 空状态：「还没有端口转发规则」，说明可创建本地/远程/SOCKS5 规则，并提示规则不会在应用重启后自动运行。加载失败显示固定错误与重试；无规则时不显示模拟数据。
- 页脚固定说明：非回环监听会向其他主机暴露端口，需显式确认；规则状态、监听器与连接数由主进程维护；SSH 重连不会自动迁移或重启规则；应用重启后规则保持停止。

## 12. 快速命令与命令历史（P1-04）

### 入口与抽屉

- 入口有四个：SSH 工具栏「快速命令」按钮、侧栏「命令库」「历史记录」导航项（打开抽屉对应页签）、命令面板「打开快速命令」动作、全局快捷键 `Ctrl/Cmd+Shift+K`。`Ctrl/Cmd+K` 为全局搜索（命令面板搜索模式），`Ctrl/Cmd+Shift+P` 为命令面板（命令模式），三者不互相覆盖。
- 打开时捕获当前活动标签作为目标，但仅在 SSH 状态为「已连接」且该标签 Shell 处于 `open` 时生效；否则抽屉顶部明确显示「打开时未捕获可发送终端；发送或插入前需显式选择目标」。
- 抽屉从右侧滑入，`role="dialog"`、`aria-modal="true"`、带遮罩；Esc、遮罩点击与关闭按钮均可关闭，但编辑器或发送/插入确认框打开时 Esc 只关闭上层对话框。关闭按钮自动获得焦点，抽屉不阻塞工作区。
- 标题为「快速命令」，带「现有终端输入通道」徽章；副标题说明命令只写入选定 SSH Shell，不新建 SSH Client，也不经任意 `exec` 通道执行。
- 顶部目标条展示打开时捕获的目标标签与会话；发送/插入确认框必须显式选择目标，抽屉不会因后台标签切换而改写目标。

### 命令库

- 「命令库 / 历史」使用 `role="tablist"` 与 `role="tab"`，标签带条目计数；命令库标签右侧有「新建」按钮。
- 工具栏：搜索「名称、分类或命令」、从主进程刷新；筛选 chip 为「全部」「收藏」与现有分类。搜索无结果与无命令分别显示空状态。
- 命令卡片：收藏按钮、名称、`内置 · 只读` / `自定义` 徽章、分类、参数数量、等宽命令正文、说明与操作。
- 内置命令只读：不可编辑、不可删除，只能收藏、复制、插入或发送；自定义命令可编辑与删除，删除使用卡片内联确认「删除后不可恢复」，不弹独立窗口。
- 操作：「插入」打开插入确认框；「发送」打开发送确认框；复制写入剪贴板并提示成功；收藏在主进程持久化，同一时间只处理一个写操作。
- 加载失败显示固定错误与「重试」；刷新不显示模拟数据。

### 历史

- 历史条目展示发送时间、连接名、目标 `host`、等宽命令正文，以及「插入」「重新发送」「复制」「删除该历史记录」。
- 顶部提供搜索「命令正文或目标主机」、刷新与「清空历史」；清空使用内联确认，展示条数并说明「不可撤销」「只影响快速命令历史，不删除应用诊断日志」。
- 全局历史关闭时显示警告条：已有记录仍可查看、插入、复制、重新发送或清空，但新的发送不会新增记录。历史列表为空时也说明需在设置启用并勾选记录。
- 历史文件损坏时显示固定错误与恢复提示：可在设置清空历史以重建空文件，其他操作不会覆盖损坏文件。
- 抽屉页脚固定披露：插入不追加回车，发送在确认后写入并回车；写入成功只表示已交给 SSH Shell，不代表远端执行成功；历史保存在 `command-history.json`，未额外加密，不记录终端输出或退出码。

### 发送/插入确认框

- 宽度 620px 的模态框；标题「确认发送快速命令」或「插入快速命令」，说明命令名与分类；来自历史时说明正文原样发送、不会重新解析参数。
- 参数区按模板自动生成输入框，支持默认值；提示「按字面单次替换；不进行额外 shell 转义，请自行确认参数内容」。模板畸形时显示 `role="alert"` 并禁用主操作。
- 「最终命令预览」使用只读等宽 `pre` 展示渲染后正文；发送时预览正文与随后写入终端的正文一致。
- 「目标终端（显式选择）」下拉列出所有 SSH 已连接且 Shell `open` 的会话；没有可用目标时禁用提交并提示先恢复终端。
- 打开时捕获的目标若已断开、重连或关闭 Shell，不自动切换到其他目标；下拉显示「之前选择的目标已不可用，请重新选择」，并禁止提交直到用户重新选择。
- 发送时若设置中启用了命令历史，显示默认勾选的「记录本次发送到命令历史」复选框，可取消；全局关闭时显示说明并强制不记录。
- 主按钮为「确认发送」/「插入到终端」，提交期间禁用并显示「发送中…」/「插入中…」；插入成功提示未追加回车、未执行；发送成功提示回车已发送，远端是否执行成功以终端输出为准。
- 写入成功但历史持久化失败时，命令仍视为已发送，同时以警告 Toast 明确「命令已写入终端，但历史未记录」；不得回滚或重发。
- 失败时保留对话框并显示固定错误；用户可修正后重试。重试复用同一 compose 请求 ID，主进程拒绝重复写入。
- 模态框底部说明发送/插入的真实语义；不提供“自动执行新创建命令”“后台标签自动切换”“多目标群发”等能力。

### 命令编辑器

- 「新建快速命令 / 编辑快速命令」模态框宽 620px；字段为命令名称（≤64）、分类（≤32，带已有分类建议）、说明（≤256）、命令正文（≤4,096，单行）与自动推导的参数默认值（≤16 个，每个 ≤512）。
- 正文使用 `{{参数名}}` 声明参数；实时解析并在下方生成默认值输入框；畸形占位符、重复参数、控制字符或超过上限时就地显示 `role="alert"` 并禁止保存。
- 提示文字明确：参数按字面单次替换，不做额外 shell 转义，没有 `eval` 或本地 Shell；首版内置命令均为只读诊断，自定义命令可能修改远端状态。
- 「保存命令」只持久化，不执行命令，也不会因连接建立或重连自动运行；保存成功显示 Toast「保存不会自动执行命令；请在命令库中预览后手动发送」。
- 编辑时命令已被删除则禁用保存并显示固定错误；提交失败保留输入。

## 13. 设置页

- 分类导航：设置分为外观、终端、文件传输、诊断日志、本地存储与凭据、应用信息、会话与传输记录、快捷键八类。左侧为带图标的分类栏，打开设置时默认选中「外观」；点击分类只显示对应分区，其余分区保留挂载但以 `hidden` 隐藏，切换分类不会重置已加载的数据或面板内状态。分类选择只是会话内界面状态，不写入设置，重新进入设置时回到外观。
- 可访问性：分类栏使用 `role="tablist"` / `role="tab"`，分区使用 `role="tabpanel"` 并通过 `aria-labelledby` 关联；活动项设置 `aria-selected="true"` 与 `tabIndex=0`，其余项为 `-1`。支持 ↑/↓/←/→ 循环切换、Home/End 跳转，焦点随选中项移动。设置读取失败、降级与恢复警告横幅位于分类栏上方，不随分类切换隐藏。
- 响应式：宽度不超过 1080px 时分类栏由左侧纵向列表切换为顶部可横向滚动的标签条；壁纸模式下分类栏使用玻璃底与香槟金活动态，活动指示条在窄屏改为底部。
- 宽度：桌面宽度下设置内容区占满工作区，左右内边距均为 20px，右侧分区边框到窗口的距离与左侧分类栏到窗口或主侧栏的距离一致；主侧栏展开或收起时均不保留额外空白。
- 高度与滚动：桌面宽度下分类栏与当前分区撑满模块剩余高度，底边保持统一 16px 内边距；分区标题固定，内容区独立纵向滚动，滚动条隐藏但滚轮与键盘滚动仍可用。窗口过矮时分类栏自身也在内部滚动且不显示滚动条。窄屏时顶部标签条保持内容高度，右侧分区继续撑满剩余高度。
- 外观：按「经典主题 / DBX 色板」分组。经典组为 Aurora 极光（蓝紫青弥散渐变 · 推荐，默认）、Obsidian 曜石（纯色深色 · 低干扰）、Mist 柔光（浅色低饱和渐变）；DBX 组为 Pearl、Mist 晨雾、Graphite、Cobalt、Sage、Amber、Blush、VS Code、IDEA、Xcode、JetBrains、Cursor、Claude 共 13 张色板卡。每张卡带浅/深双色 swatch 与 `aria-pressed`，点击立即应用到顶栏、侧栏、面板、连接状态容器与对话框并持久化。
- 经典主题下方提供「经典主题跟随系统」复选框：勾选后按操作系统深浅色在 Aurora（深色）与 Mist（浅色）之间自动切换，并显示当前解析结果。DBX 组提供独立「DBX 深浅色」分段控制（跟随系统 / 浅色 / 深色），未选中 DBX 色板时禁用并说明原因；切换 OS 外观时仅跟随系统模式重新解析。
- 渐变强度：0–100 滑杆（默认 35），实时显示数值；只调节 Aurora 与 Mist 的背景光斑可见度，Obsidian 与 DBX 色板不受影响。
- 字体：界面字体（系统默认 / Segoe UI 优先 / 微软雅黑优先）与界面字号 12/13/14/15，通过 `--tf-font-ui` 与 `--tf-font-scale` 立即缩放全部界面排版；终端字体 8 种预设与字号 10–20。两组均带实时预览：界面预览展示当前字体/字号的中英文与数字，终端预览使用当前终端底色、前景色与 ANSI 强调色。终端字体/字号调整触发 FitAddon 重新计算与 PTY 尺寸同步。
- 壁纸卡片：展示当前图片预览或「未导入」空态、`启用壁纸模式` 复选框、选择/更换图片、移除，以及轻/标准/浓三档浓度（`role="group" aria-label="壁纸浓度"`）。未导入时开关与浓度禁用；导入成功后自动开启；移除后关闭壁纸模式。说明文字明确“终端、输入框与正文保持不透明”。
- 终端：字体与字号已移至外观页并提供预览，终端页显示当前值摘要与「前往外观设置」入口；光标样式 block/underline/bar、闪烁开关、回滚行数 1,000/5,000/10,000/20,000 保留在终端页。所有修改立即应用到 xterm，不重建终端或 SSH 连接。
- 传输：全局并发 1–4、每会话并发 1–2；降低全局上限到低于每会话值时同时提交两者；说明降低上限不会终止运行中任务。
- 诊断日志：日志级别 error/warn/info/debug、目录、文件数量、写入失败计数、文件大小/修改时间；支持刷新、导出脱敏日志与打开日志目录。导出路径由主进程原生保存对话框决定。
- 应用信息：名称、版本、Electron/Chromium 版本、平台、是否打包，均通过只读 preload bridge 获取；bridge 失败时显示错误说明与重试。
- 本地存储与凭据：显示连接配置与设置持久化语义、操作系统凭据保护类型/可用性、主机密钥策略；安全存储不可用时明确提示不会降级为明文。主机密钥列表显示端点、算法、指纹与信任时间，删除需要确认，且不会断开当前会话。
- 会话与传输记录：命令历史开关默认关闭；说明启用后只有发送确认中勾选「记录本次发送」才保存渲染后的命令正文与目标会话信息，终端输入、输出、退出码和普通日志不会进入历史；关闭后仍可查看和管理已有记录但不会新增。「清空命令历史」使用确认弹窗，说明只删除本机 `command-history.json`、不影响自定义命令/诊断日志/连接配置、未额外加密且清空后不可恢复；历史文件损坏时清空会写入空历史以恢复可用状态。
- 「自动重连」复选框默认关闭，标签为「启用自动重连」，状态文案「已启用 / 已关闭（默认）」。说明文字明确：仅对网络错误、连接超时、DNS 解析失败、连接被拒绝或服务器关闭连接重试，最多 5 次，间隔 1、2、4、8、15 秒；认证失败、主机密钥变化、手动取消、主动断开、关闭标签或应用退出都不会触发自动重试。关闭开关会立即停止所有等待中的自动重连计时器；设置写入失败时回滚并显示错误，不假装已保存。
- 操作：恢复默认外观、清空传输记录、断开全部 SSH 会话；清空只移除已结束任务，进行中的传输、待处理冲突与 `interrupted` 任务仍保留；每条操作均有说明真实影响范围的 Toast。
- 设置读取失败时显示 `role="alert"` 横幅与「重新读取」；恢复警告逐条展示；写入失败时回滚仍未被后续修改的字段并显示危险 Toast。
- 快捷键说明与安全边界说明。
- 主题（`theme`: 16 套风格之一或 `system`）、DBX 明暗（`dbxThemeMode`: `system|light|dark`）、界面字体/字号、终端字体/字号、渐变强度（0–100）、终端光标/回滚、传输并发、日志级别、壁纸开关与浓度、`commandHistoryEnabled` 与 `autoReconnectEnabled` 持久化到主进程 `settings.json`（v6），重启后恢复；v1–v5 文件在读取时于内存迁移（旧深色 → Aurora、旧浅色 → Mist、跟随系统 → 跟随系统；v5 缺失的 `dbxThemeMode` 按 `system`、`uiFontFamily` 按 `system`、`uiFontSize` 按 13 处理），缺失的 `gradientIntensity` 按默认 35、缺失的 `autoReconnectEnabled` 按 `false` 处理。分屏布局、窗格绑定、焦点、自动重连计时器与尝试次数不持久化。连接配置、凭据与主机密钥不受设置保存影响。壁纸图片由主进程保存在用户数据目录，界面只接收 data URL 预览。快速命令与命令历史分别保存在 `quick-commands.json` 与 `command-history.json`；历史默认关闭、最多 200 条，与应用日志分离且未额外加密。

## 14. 命令面板

- 两种模式：搜索（服务器在前，同时匹配命令关键词）与命令（命令在前），共享一个 `aria-modal` 对话框；`Ctrl/Cmd+K` 打开搜索模式（顶栏全局搜索按钮等效），`Ctrl/Cmd+Shift+P` 打开命令模式。
- 搜索匹配连接（标签、名称、地址、用户、端口）与命令（名称、正文、关键词）；空结果展示提示。
- 键盘：`↑/↓` 循环选择，`Home/End` 跳转，`Enter` 执行，`Esc` 关闭，点击遮罩关闭；`aria-activedescendant` 同步活动项。
- 命令：新建连接、切换到首页（工作台）、打开连接管理、打开 SFTP、打开传输队列、打开快速命令、打开设置、切换到下一主题（16 套风格按目录顺序循环，`title` 显示下一主题名）、收起/展开侧栏；服务器结果会新建独立 SSH 会话标签，而非复用已有标签。快速命令动作与 `Ctrl/Cmd+Shift+K` 等效，只打开抽屉，不会自动发送任何命令。
- 无未实现命令占位按钮。

## 15. 统一反馈与可访问性

- Toast 四种语气：info/success/warning/danger，用于操作反馈和错误；不替代字段级错误。
- 所有可交互按钮都有可观察的前端行为；未实现能力以禁用控件和显式「未实现」说明出现。
- 焦点样式使用 `:focus-visible` 与统一 focus ring；模态框具备 focus trap、Esc 关闭、遮罩关闭。
- 纯图标按钮均带标签与 title；状态不只依赖颜色，同时带文本标签。壁纸预览图带 `alt="当前壁纸预览"`，浓度按钮使用 `aria-pressed`，壁纸浮层菜单可通过 Esc/点击遮罩关闭。
- 快速命令抽屉使用 `role="dialog"` + `aria-modal`，视图切换使用 `role="tab"`/`aria-selected`；命令卡片使用 `article` + 可访问名称，收藏/复制/编辑/删除按钮均有 `aria-label`；删除与清空使用内联 `alertdialog`；发送/插入与编辑器使用标准模态焦点陷阱、Esc 关闭与字段错误 `role="alert"`。
- 遵循 `prefers-reduced-motion`，减少动画与过渡。
- 界面不包含模拟数据：传输任务、SSH、终端与远程 SFTP 数据均来自主进程；任务卡片上的路径、大小、进度和错误由主进程快照渲染，不在前端伪造。
